無限につづく小数を32ビットの2進数でどう表すのか？

√2 = 1.41421356…

0.41421356 × 2 × 2...を繰り返す方法では誤差がでてしまう。

√2 を2³²倍して整数部分を作り出す。つまり、√2 × 2³² = √(2⁶⁵)を計算する。

ニュートン法：平方根を求める

nxn|xn − √2|正しい桁

誤差がおおよそ二乗で縮むので、正しい桁数が反復ごとに倍々になる（二次収束）。

接線とx軸の交点： x' = x − (x²−2)/(2x) = ( x + 2/x ) / 2　←「予想と2÷予想の平均」と同じ

ビットは「整数」で取り出す

小数のまま2進にすると桁が足りず誤差が出る（10進で約10桁は必要）。2³²倍して整数にする。

√2 × 2³² = √(2⁶⁵)

整数のニュートン法 x ← (x + N÷x) ÷ 2 で、値が変わらなくなるまで。
